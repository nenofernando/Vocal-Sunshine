# NF Vocal Sunshine
Guided eleven-stage vocal processor (own design; the idea came from a "vocal chain in minutes" wizard seen in a video — never copy another product's name, art or presets).
Signal chain, zero latency: LOW/HIGH CUT (global knobs) -> CLEAN -> FIX -> EQ (4 draggable points) -> TONE -> CONTROL -> DE-ESSER -> COLOR -> DOUBLE (double/stack/wide; shown as DOUBLE in the UI, `Voices` in code) -> HARMONY (pitch-shifted interval voices) -> REVERB -> DELAY -> FINISH, then Output + Mix (12 stages; CONTROL stage is shown as COMPRESSOR). One stage is shown at a time:
big amount knob, 3 styles, module on/off, 2 option switches, before/after waveform (input vs the signal after the selected stage), activity meter, stage rail at the bottom.
- Repo `~/NF-Vocal-Sunshine` (local git, not pushed). Version: `CMakeLists.txt` line 2 only (no installer yet). Licence ON by default since 2026-11-22 (owner: 'tem que ter chave de acesso, chave curta'); see the Licence section.
- Ids: bundle `com.nfaudiotools.nfvocalsunshine`, manufacturer `Nfat`, code `Nfsu`, licence code would be `NF_VOCAL_SUNSHINE`.
- Look (v0.1, redesigned 2026-11-21 to differ from the reference video): brushed-graphite faceplate with rack screws, module list on the left (LED = module on/off, click = select), segmented STYLE selector, A/B push buttons, silver hardware knobs (printed scale, no ring texture), LCD value window, vertical LED meter, master strip (low cut / high cut / output / mix) with live values. Value texts are set in `setupValueTexts()` after every attach because SliderAttachment overrides them.
- Window 810 x 500 (exception to 810 x 270), size stored in state (`uiWidth`), selected stage in state (`stage`); logo double-click resets. Official logo image only (`Assets/NF_Audio_Tools_Logo_MAIN_800.png` = the 800 px version of the official MAIN logo, rescaled to the exact pixel size when painting).
- Preset tab 157 x 21 top right `[<] name [>]`, 11 factory presets (`Presets.h`), name in state (`presetName`).
- Stage names/styles/options/colours/defaults: `Source/Stages.h` (single table for DSP defaults and UI). DSP: `Source/SuiteDSP.h`. Params per stage: `s<N>amt|mode|on|a|b` (N = 1..12) + `lowcut`, `highcut`, `ctlatk|ctlrel|ctlratio` (compressor trims, 50 = style value), `hv1..hv6` (harmony intervals), `hkey`, `eq1..4 f|g|q` (EQ points), `vspread` (voices width, dragged in the VOICES display), `output`, `mix`, `bypass` (delay time = DELAY style, follows host BPM).
- DSP notes: FIX resonances are 3 self-calibrating subtractive band cuts (320 / 1000 / 3400 Hz, relative to each band's own running average); CONTROL = level rider (slow) -> linked compressor; COLOR extra terms are DC-blocked so the stage is transparent at 0; FINISH = drive -> soft clip -> peak limiter at -1 dB (attack is fast but not look-ahead, final soft clip catches overshoots).
- Build (Mac is Intel): `cmake -B build -DCMAKE_OSX_ARCHITECTURES=x86_64 -DFETCHCONTENT_SOURCE_DIR_JUCE=$HOME/JUCE -DNFVocalSunshine_BUILD_TOOLS=ON`; `NFVocalSunshineSnapshot out.png [stage 0..11] [scale] [preset]` renders the UI; `NFVocalSunshineSmokeTest` checks every preset and each stage's DSP behaviour.
- HARMONY DSP (own code, no other NF plug-in's code): YIN-style pitch tracker on a ~12 kHz decimated copy; each interval voice = two Hann-crossfaded grains on the shared voice delay line, grain length = an even number of pitch periods so the two grains add in phase; zero latency. MAJOR/MINOR modes pick the interval from the detected lead note inside the chosen key; FIXED uses plain semitones.
- EQ DSP: low shelf, 2 bells, high shelf, nodes dragged on the spectrum (wheel = Q); styles are one-shot starting curves.
- PITCH (auto-tune) stage was built and then REMOVED at the owner's request ("por enquanto", 2026-11-21). The code is in git commit 75a6823 (grain shifter + tracker + piano-roll display + tests) if it comes back.
- Big knob style: KNOB button in the header cycles metal / sun / full moon (`knobStyle` in state). Default = SUN (owner's choice 2026-11-21).
- DE-ESSER is its own stage (after the compressor): band-pass detector + subtractive cut, FREQUENCY (`desfreq`) and MAX CUT (`desmax`) knobs, styles = bandwidth (narrow / medium / wide), LISTEN plays only the band, SMOOTH = slower release. FIX is now only the three resonance cuts (boxy+nasal / harsh).
- Colours: neon palette (one hue per stage in `Stages.h`, EQ = neon pink); text and LCD digits get a soft neon halo.
- DELAY has a LO-FI knob (`dlofi`, inside the feedback loop so every repeat gets dirtier): bit + sample-rate crush, darker low-pass, thinner lows, soft saturation, tape wow/flutter on the delay time. Waveform lanes: brighter, taller, neon glow on the processed lane.
- DE-ESSER frequency is also dragged directly in its display (handle on the band, double-click resets); VOICES width likewise.
- Every stage except FINISH has its own LOW CUT / HIGH CUT / OUTPUT / MIX (`s<N>lc|hc|out|mix`): the cuts filter the stage's effect (what it changes or adds), MIX scales that effect, OUTPUT trims the stage level; defaults are transparent. The strip at the lower right shows the selected stage's four knobs; on FINISH it is the global master (`lowcut`, `highcut`, `output`, `mix`). Presets do not touch these.
- HARMONY AUTO key (`hauto`, default on): the key is read EXACTLY like Mixa's `detectKey` (`Analysis.h`): 4096-point FFT / hop 2048, sqrt magnitude of bins 65-2000 Hz within 0.3 semitone of a note summed per pitch class, correlated with the 24 Aarden-Essen profiles; accumulated from the start (half-life 10 min) until RESET; first answer after 6 s; confidence = Mixa's formula scaled by the evidence heard; hysteresis; a close runner-up is shown. Checked on 6 real vocals: same key and mode as a Python copy of Mixa's method (`KeyTool` in Tests). The older pitch-tracker histogram was dropped: it flipped between E, Eb and Ab on the same vocal (Mixa reads the whole mix, the plug-in only the voice, so relative major / minor can be confused). Needs 3 s of singing; RESET forgets; choosing KEY or a style by hand switches AUTO off and keeps what it had found; FIXED always keeps plain semitones.
- DELAY has FEEDBACK (`dfb`, 0-95 %, default 38 % = the old fixed value) next to LO-FI.
- DELAY time has its own choice `dtime`: 1/16, 1/8, 1/4, dotted 1/4, 1/2, 1 bar (follows the host bpm; the old three delay styles are not used any more, presets map to `dtime`).
- HARMONY AUTO has two readings (`hnotes`, default on): NOTES = pitch-tracker histogram (best fit to the sung notes: 72-89 % of the notes inside the scale on 6 real vocals, vs 56-90 % for the spectral reading) and SONG = Mixa's exact reading. `KeyTool` prints the comparison.
- HARMONY voice engine = pitch-synchronous grains (PSOLA style, `renderHarmonyVoice` in SuiteDSP.h): grains of two source periods placed every output period, source offsets in whole periods so overlapping grains add in phase. FORMANT knob (`hformant`, -12..+12 st, 0 = natural colour) sets the grain content speed; the pure-pitch part is limited to 0.8-1.6, so beyond about +-4 semitones the formants follow the pitch partially. Tested with a 1 kHz-resonance source.
- UI simplification (owner: two readings would confuse users): only the sung-notes reading is offered; `hnotes` stays in the state (default true, not automatable) and the spectral / Mixa reading only runs if it is switched off by hand in a saved state. The display shows 'AUTO: E MINOR - 74 % sure'.
- HARMONY tuning fixes (owner: 'agora sinto desafinada'): intervals are built on a stable note (changes only when the voice leaves it by 0.7 semitone), a new interval starts at once (no gliding through the notes between: it was 11-15 % of the singing time and 4-5 interval changes/s on real vocals, now 0 % and about 2.5/s); with AUTO on the harmony stays silent until a key is known (first answer after 1.5 s of singing, shown as 'still listening' until 4 s); the hidden `hnotes` state is ignored (a saved SONG choice could still decide). Engine accuracy measured in the smoke test: steady tones < 1 cent, vibrato +-40 cents tracked within about 8 cents.
- Waveform lanes (before / after the selected stage): one smooth mirrored envelope filled with a horizontal fade, lighter core, glow and a crisp outline on the two long edges (no separate bars).
- Waveform colours: both lanes are neon (ORIGINAL = ice-blue 0x7df3ff, AFTER = the stage's neon colour), saturated fill, double neon glow on the edges, light tint core, labels on a dark backing so they stay readable.
- Left vertical meter: reduction / activity for CLEAN, FIX, COMPRESSOR, DE-ESSER and FINISH; for every other stage it shows the stage's real output level (peak of the last 80 ms, -48..0 dB) and falls to zero when the host stops calling the plug-in (it used to show the knob position, which looked stuck).

## Licence (access key) and installers
- Same design as NF Brutal: short key `NFVS-XXXX-XXXX-XXXX-XXXX` (product `nfvs`) traded at POST /activate on the licence worker `https://mixa-licence.nenovoice.workers.dev`
  for the signed long key `NFVS2|name|expires|id` (RSA-2048, checked offline), 2 computers per key, weekly online check, 30 days offline grace. Plug-in is muted until activated; the editor shows
  `Source/License/VocalSunshineLicenseOverlay.h`. Key file: `~/Library/NF Audio Tools/NF Vocal Sunshine/licence.key` (Windows `%APPDATA%`).
- Private key `~/.nfvs_license/private.pem` (+ `pkcs8.b64` = worker secret `NFVS_KEY`): NEVER commit, the owner must back it up. Public half in `Source/License/NFVSLicensePublicKey.h`.
- CMake option `-DNFVocalSunshine_LICENSE=OFF` = development build without the lock (the test tools never enforce it). Default ON, so a build cannot ship unlocked by accident.
- The worker code with the product `nfvs` is committed locally in `~/Documents/mixa-worker-wt` (branch license-worker-short-keys, commit 9eecaec) but NOT DEPLOYED and the secret NOT uploaded: both need the owner's OK (production). Until then keys cannot be created and the plug-in cannot be activated online.
- Mac: `bash Installer/macos/build_dmg.sh` -> `~/Desktop/NF Vocal Sunshine <version>.dmg` (universal, VST3 + AU, key ON, ad-hoc signed, .pkg unsigned; refuses a build without the key code or not universal).
- Windows: `bash Installer/Windows/build_windows_on_mac.sh` -> `~/Desktop/NF Vocal Sunshine <version> Setup.exe` (VST3 x64 cross-compiled with clang-cl + xwin; stub in `Installer/Windows/stub`). Never run on a real Windows machine from here.
- `LicenseCheck` tool (Tests): `NFVocalSunshineLicenseCheck "<long key>"` verifies a key with the plug-in's own code. DMG / EXE are never committed.
